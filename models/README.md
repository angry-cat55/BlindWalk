# 🧠 BlindWalk AI Models Hub

`BlindWalk` 프로젝트에서 사용하는 AI 인지 및 깊이 추정 딥러닝 모델 저장소입니다.

## 📁 디렉토리 구조
* **`active/`**: 현재 서비스 및 개발 파이프라인에서 기본으로 실행되는 모델 가중치 파일과 상세 분류 명세서.
  * `*.pt`: 클래스 인스턴스 세그멘테이션 모델
  * `*.tflite`: 안드로이드 실기기(NPU/GPU 가속) 온디바이스 탑재용 세그멘테이션 경량화 모델
  * `depth.onnx`: MiDaS_small 기반 단안 깊이 추정 모델
  * `README.md`: 클래스 분류표 및 모델에 대한 설명가이드

## 🔄 모델 동적 교체 안내
`BlindWalkAIPipeline`은 모델 가중치를 로드할 때 모델 내부의 `model.names` 메타데이터를 런타임에 직접 동적으로 읽어옵니다.
따라서 다른 가중치 파일로 교체하더라도, 별도의 코드 수정 없이 모델 경로만 변경하여 실행할 수 있습니다.
상세한 클래스 및 입출력 명세는 [`active/README.md`](active/README.md)를 참고하십시오.

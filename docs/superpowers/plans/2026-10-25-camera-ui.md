# 카메라 중심 UI 구현 계획

승인한 ui-draft.html을 기준으로 구현한다. 앱 이름 옆 마름모와 카드 왼쪽 강조선은 제거한다.
기존 feature/ai-feedback-integration의 미커밋 통합 작업을 이어서 진행하며 commit/push는 하지 않는다.

- [x] AiFrameInput 결과에 원본 좌표계의 검출 목록과 단조 시각을 묶어 전달한다. 모델·판단 규칙은 변경하지 않는다.
- [x] CameraScreen을 자동 진입·같은 화면 일시정지/재시작·권한/오류 복구 UI로 변경한다. 상태 음성·TalkBack을 제공한다.
- [x] DetectionOverlay에서 FIT_CENTER 4:3 좌표를 변환해 영역·박스·한글 이름을 그린다. 오래된 결과를 지운다.
- [x] 좌표 매핑 단위 검사, 빌드·lint·기존 테스트 및 가능한 기기에서 화면/정지/재시작을 확인한다.
- [x] 공유 문서를 갱신하고 임시 HTML을 삭제한다.

새 라이브러리와 추적 기능은 추가하지 않는다. 거리·신뢰도·FPS·안전 경로는 기본 화면에 표시하지 않는다.

추가 승인: Preview는16:9로 넓게, AI는중앙4:3 crop후640×480 기존전처리를 사용한다. 마름모·카드왼쪽강조선은 없다.

검증: assembleDebug/testDebugUnitTest/lintDebug 통과. Kotlin19개·Python101개 통과, lint오류0(경고30). 에뮬레이터 콜드 실행 준비 화면·일시정지 화면·다시 시작의 카메라 장치 연결을 확인했다. 실제 프레임/검출 표시의 시각적 정합과 실기기 성능은 미검증이다. 에뮬레이터에서 준비 지연·검정 Preview가 관측돼 촬영 성공으로 기록하지 않는다.

추가 로그 확인: 에뮬레이터가 실제 1280×720 프레임을 수신했고 YOLO·깊이 추론으로 객체1~2개를 반환했다. 에뮬레이터는 CPUfallback이며 수초의 추론 지연이 있어 1.2초를 넘는 검출 표시는 폐기한다. 실기기 검출 위치 정합·GPU 성능의 재확인은 아직 수행하지 않았다.
